# pages/camera/ 拍照识别页面

本页面用于实现「拍照翻译」功能，用户可通过摄像头拍照并将图像发送到后端进行识别盲文。

---

## ✅ 页面功能流程

1. 打开页面，默认展示后置摄像头
2. 用户点击黑色圆形拍照按钮（`takePhoto`）拍摄图像
3. 拍照成功后锁定图像（不再显示拍照按钮）
4. 展示两个按钮：
   - ❌ 取消重拍（`retakePhoto`）
   - ✔ 确认识别（`confirmPhoto`）
5. 用户点击 ✔：
   - 显示扫描动画（上下往返白线）
   - 延迟 2.5 秒后上传图像给后端 `/ocr`
   - 超过 4 秒未返回 → 提示“网络超时”
   - 成功返回结果 → 跳转 `pages/result/result`
   - 失败返回或空文本 → 提示“识别失败”，并重置状态

---

## 📄 camera.js 方法说明

| 方法名                | 说明                                                        |
| --------------------- | ----------------------------------------------------------- |
| `takePhoto()`         | 使用后摄拍照，生成 `photoPath`，设置 `photoTaken: true`     |
| `retakePhoto()`       | 取消拍照，清空状态，返回拍摄模式                            |
| `confirmPhoto()`      | 设置 `scanning: true`，开始动画并调用 `uploadWithTimeout()` |
| `uploadWithTimeout()` | 上传文件至 `/ocr` 接口，支持超时处理                        |
| `goBack()`            | 返回上一页（首页）                                          |

---

## 📂 权限与依赖

- 必须启用小程序摄像头权限
- 使用组件：`<camera>`、`<image>`
- 后端需提供 OCR 接口：`POST /ocr`，返回 JSON `{ text: '识别文字' }`

---

## 🚧 注意事项

- 若接口返回格式错误，会自动 `catch` 并提示识别失败
- 若用户长时间无返回，将触发 `timeout` 并提示网络超时
- 一旦出错将自动回到拍照状态，不需用户刷新

---

  "text": "识别出的内容"

# pages/result/ 识别结果展示页面

该页面用于展示从 `/ocr` 接口识别返回的文本结果，作为拍照识别的最终展示界面。

---

## ✅ 页面功能流程

1. 用户在 `camera` 页面拍照确认后，图像被上传
2. 后端识别成功后，跳转至 `pages/result/result` 页面
3. 页面通过 `onLoad(options)` 接收传入的参数 `text`
4. 使用 `decodeURIComponent()` 处理后，展示在页面上

---

## 📄 result.js

```js
Page({
  data: {
    resultText: ''
  },
  onLoad(options) {
    const result = decodeURIComponent(options.text || '');
    this.setData({
      resultText: result
    });
  }
});
```

- 支持从 URL 参数中获取内容
- 自动设置到 `resultText` 数据中用于页面渲染

## 🧾 接口配合要求

- 此页面不主动发起请求，仅作为结果展示
- 必须由 `camera.js` 识别成功后通过如下方式跳转传参：

```js
wx.navigateTo({
  url: `/pages/result/result?text=${encodeURIComponent(resultText)}`
});
```

## 📌 注意事项

- 若 `text` 参数为空或格式异常，将显示空白
- 页面不支持后退自动重识别，请返回首页或重拍
- 可在未来扩展 “复制结果”、“保存结果”、“返回首页”等功能按钮
